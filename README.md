# TCS Financial Modeling & Valuation

## Project Overview

This project presents a comprehensive financial modeling and valuation analysis of Tata Consultancy Services (TCS).

The model covers historical financial analysis, financial forecasting, WACC calculation, DCF valuation, comparable company analysis, sensitivity analysis, and other financial risk and performance metrics.

## Objectives

- Analyze historical financial performance
- Forecast future financial statements
- Estimate the Weighted Average Cost of Capital (WACC)
- Perform Discounted Cash Flow (DCF) valuation
- Conduct Comparable Company Analysis
- Perform sensitivity analysis
- Evaluate financial performance and risk
